# Ejercicios de Python

## Descripción

En este repositorio se encuentran los ejercicios que desarrollé durante las prácticas de la asignatura de Programación en Python. A través de ellos trabajé diferentes conceptos del lenguaje, como estructuras condicionales, estructuras iterativas y funciones. Cada archivo corresponde a un ejercicio independiente.
## Estructura del proyecto

El proyecto está organizado de la siguiente manera:

```

│   ├── 01.py
```

## Requisitos

Para ejecutar los ejercicios es necesario tener instalado **Python 3**.

Puedes comprobar que Python está instalado ejecutando alguno de estos comandos en la terminal:

```bash
python --version
```

o

```bash
python3 --version
```

## Cómo ejecutar los ejercicios

Cada ejercicio funciona de manera independiente, por lo que solo debes abrir una terminal, ubicarte en la carpeta del proyecto y ejecutar el archivo que desees.

### Ejemplos

Ejecutar un ejercicio de funciones:

```bash
python funciones/01.py
```

Ejecutar un ejercicio de condicionales:

```bash
python condicionales/01.py
```

Ejecutar un ejercicio de estructuras iterativas:

```bash
python iterativas/01.py
```

Si utilizas Linux o macOS, reemplaza `python` por `python3`.

```bash
python3 funciones/01.py
```

## Contenido del repositorio

### Condicionales

En esta carpeta se encuentran ejercicios relacionados con:

- Uso de `if`.
- Uso de `if...else`.
- Uso de `if...elif...else`.
- Operadores relacionales.
- Operadores lógicos.
- Evaluación de diferentes condiciones.

### Iterativas

Esta carpeta contiene ejercicios donde se aplican estructuras repetitivas como:

- Ciclo `while`.
- Ciclo `for`.
- Función `range()`.
- Uso de `break`.
- Uso de `continue`.
- Ciclos anidados.

### Funciones

En esta carpeta se desarrollan ejercicios relacionados con:

- Definición de funciones.
- Parámetros y argumentos.
- Valores de retorno.
- Parámetros con valores por defecto.
- Uso de `*args` y `**kwargs`.
- Validación de datos.
- Documentación mediante **docstrings**.

## Observaciones

- Todos los ejercicios fueron desarrollados en Python 3.
- Cada archivo puede ejecutarse de forma independiente.
- Algunos ejercicios muestran resultados directamente en la consola, mientras que otros pueden requerir datos ingresados por el usuario, dependiendo del objetivo del ejercicio.
- Otros solicitan información al usuario mediante la función `input()`, por lo que es necesario ingresar los datos cuando el programa lo solicite.
