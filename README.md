Lógica utilizada

Para resolver los ejercicios se siguió la siguiente metodología:

1. Declarar las variables necesarias.
2. Solicitar datos al usuario cuando era necesario.
3. Realizar los cálculos utilizando operadores matemáticos.
4. Guardar los resultados en variables.
5. Mostrar los resultados mediante la función `print()`.
6. Documentar el código con comentarios para facilitar su comprensión.
