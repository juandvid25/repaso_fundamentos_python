# Descripción

Este repositorio contiene el desarrollo de los laboratorios realizados durante el curso de **Programación en Python**.

Cada ejercicio fue creado con el propósito de fortalecer los fundamentos de programación, aplicando conceptos básicos del lenguaje Python y desarrollando soluciones mediante algoritmos sencillos.

Durante el desarrollo de los laboratorios se aplicaron buenas prácticas como la organización del código, el uso de comentarios para explicar los procesos realizados y la documentación de cada ejercicio para facilitar su comprensión.

Los programas desarrollados permiten practicar los siguientes temas:

- Uso de la función `print()`.
- Parámetros `sep` y `end`.
- Caracteres de escape en cadenas de texto.
- Declaración y uso de variables.
- Operadores matemáticos.
- Conversión de tipos de datos.
- Creación de expresiones matemáticas.
- Conversión de unidades.
- Conversión de moneda.
- Desarrollo de algoritmos básicos mediante entradas y salidas de información.

# Descripción de los archivos

| Archivo | Descripción |
|---------|-------------|
| `print.py` | Primer programa desarrollado utilizando la función `print()` para mostrar información en pantalla. |

# Operadores matemáticos utilizados

Durante el desarrollo de los laboratorios se utilizaron diferentes operadores matemáticos para resolver problemas y realizar cálculos.

| Operador | Función |
|----------|---------|
| `+` | Suma |
| `-` | Resta |
| `*` | Multiplicación |
| `/` | División |
| `//` | División entera |
| `%` | Módulo o residuo |
| `**` | Potencia |

Estos operadores fueron utilizados en ejercicios de cálculos matemáticos, conversiones de unidades, operaciones con variables y resolución de algoritmos.

# Lógica utilizada para resolver los ejercicios

Para desarrollar cada programa se siguió una metodología básica de programación:

1. Identificar el problema a solucionar.
2. Declarar las variables necesarias para almacenar la información.
3. Solicitar datos al usuario mediante la función `input()` cuando fue necesario.
4. Realizar los cálculos utilizando operadores matemáticos.
5. Guardar los resultados obtenidos en variables.
6. Mostrar la información final mediante la función `print()`.
7. Documentar el código mediante comentarios para facilitar su comprensión.

# Algoritmos desarrollados

El archivo `algoritmo.py` contiene la solución de 16 ejercicios prácticos donde se aplican los fundamentos aprendidos durante el laboratorio.

Los ejercicios desarrollados fueron:

1. Cálculo del puntaje total de un jugador.
2. Tiempo total de juego.
3. Daño causado por ataques.
4. Experiencia obtenida en una partida.
5. Porcentaje de vida restante.
6. Oro obtenido durante una misión.
7. Velocidad del personaje.
8. Costo de mejoras.
9. Tiempo restante de una misión.
10. Nivel promedio de un equipo.
11. Daño crítico.
12. Conversión de minutos a horas.
13. Porcentaje de misiones completadas.
14. Costo total de objetos comprados.
15. Tiempo promedio de partidas.
16. Porcentaje de enemigos derrotados.

Estos ejercicios permitieron aplicar variables, operadores matemáticos, entrada de datos y generación de resultados.
