# Ejercicios de Operadores Matemáticos en Python

## Introducción
En este documento se presentan las soluciones de los ejercicios relacionados con operadores matemáticos en Python.
Cada ejercicio fue resuelto de forma manual teniendo en cuenta la prioridad de operaciones y comprobadas Python.

Para resolver los ejercicios se aplicó la siguiente jerarquía:
1. Paréntesis `()`
2. Potencias `**`
3. Multiplicación `*`, división `/`, división entera `//` y módulo `%`
4. Suma `+` y resta `-`

---

# Ejercicio 1

## Expresión

```python
5 + 3 * 2
```

## Paso a paso

1. Identificar la prioridad de operaciones:

- Multiplicación `*`
- Suma `+`

La multiplicación tiene mayor prioridad que la suma.

2. Resolver la multiplicación:

```python
3 * 2 = 6
```

3. Resolver la suma:

```python
5 + 6 = 11
```

## Resultado final

```python
11
```
